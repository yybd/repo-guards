# ‏rules/ — הוראות קבע, תחת גרסאות

‏`global-CLAUDE.md` נטען **בכל סשן בכל פרויקט**, דרך symlink. זהו העותק האנגלי;
‏`global-CLAUDE.he.md` הוא אותם כללים בעברית, מונח לצדו עבור הקורא ולא עבור הסוכן:

```bash
ln -s $REPO_GUARDS/rules/global-CLAUDE.md ~/.claude/CLAUDE.md
```

הפקודה האחת הזו היא כל ההתקנה, והיא לכל מכונה בנפרד.

**כללים משלך נכתבים לצד אלה, לא בתוכם.** הקובץ הזה משותף: מי שמקשר אליו מקבל כל שורה שבו. לכן העדפה שהיא רק שלך (השפה שבה עונים לך, סגנון בית) אינה שייכת לכאן. במקום זאת הפוך את `~/.claude/CLAUDE.md` לקובץ משלך, וייבא ממנו את הכללים האלה:

```
@$REPO_GUARDS/rules/global-CLAUDE.md   ← כנתיב מלא; @ אינו מרחיב משתנים

## שלי
…
```

בדיקת ההתיישנות מקבלת את שתי הצורות: את ה-symlink, או קובץ שמייבא את זה.

## למה symlink ולא הפלאגין

פלאגין אינו יכול לשלוח את זה. פלאגינים נושאים סקילים, סוכנים, פקודות, שרתי MCP והוקים —
לא זיכרון. מפתח ההגדרות ש*כן* מזריק הוראות בסגנון CLAUDE.md, ‏`claudeMd`, **מכובד רק
מהגדרות מנוהלות/מדיניות**, שהוא משטח של מנהל מערכת ולא משהו שפלאגין של משתמש יכול להגיע
אליו.

כך שהבחירה הייתה בין symlink אל תוך ה‑repo הזה לבין הוק `SessionStart` מטעם הפלאגין
שמזריק את תוכן הקובץ כ‑`additionalContext`. ה‑symlink מנצח משום שהוא משתמש במנגנון ממדרגה
ראשונה: ‏Claude Code טוען את `~/.claude/CLAUDE.md` באופן טבעי, תמיד, בלי שום קוד שלנו
בדרך. ההוק היה משכפל את זה עם יותר חלקים נעים ואותו אופן כישלון.

**שניהם נכשלים בשקט.** ‏symlink שבור והוק שבור מסתיימים שניהם בכך שהכללים פשוט אינם שם,
ואיש אינו מודיע על כך. אם אי פעם נדמה שהכללים אינם בתוקף, בדוק קודם את הקישור:

```bash
readlink ~/.claude/CLAUDE.md && head -1 ~/.claude/CLAUDE.md
```

## זה מצטבר עם ה‑CLAUDE.md של הפרויקט — הוא אינו מחליף אותו

קובצי זיכרון מצטברים: קובץ רמת המשתמש (זה, דרך ה‑symlink) וה‑`CLAUDE.md` של הפרויקט
נטענים **שניהם**. סכמת ההגדרות נוקבת ב‑"User, Project, and Local memory types" ומציעה
‏`claudeMdExcludes` כדי להשמיט אחד — רשימת השמטה קיימת בדיוק מפני שכולם נטענים יחד.

לכן ה‑repo הזה נושא גם `CLAUDE.md` בשורש, לכללים שנכונים רק כאן. השניים משלימים זה את זה
בתכנון, וכך הם חייבים להישאר: בשונה מהגדרות, שיש להן קדימות מתועדת (משתמש ← פרויקט ←
מקומי), **לזיכרון אין מנצח מתועד**. לשני קבצים שסותרים זה את זה אין הכרעה מוגדרת, ולכן
לעולם אל תכתוב באחד כלל שמתווכח עם האחר.

הקובץ הגלובלי נקרא `rules/global-CLAUDE.md` ולא `CLAUDE.md` מסיבה אחרת — לא קדימות אלא
כפילות. ‏`CLAUDE.md` בשורש ה‑repo הזה שה‑symlink גם מצביע עליו היה מגיע לסשן שרץ כאן
פעמיים, פעם כזיכרון משתמש ופעם כזיכרון פרויקט.

## למה לא סקיל

סקיל נטען לפי התאמת תיאור — רק כשמשהו שופט אותו כרלוונטי. כלל קבע אינו יכול לתלות את עצמו
בשיפוט הזה; הוא הכי פחות צפוי להיות מופעל בדיוק כשהמשמעת מתחילה להישמט.
