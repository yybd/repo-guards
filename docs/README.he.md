# החלטות grove

**מה התיקייה הזו.** לכל החלטה ארכיטקטונית — מסמך שאומר **למה** היא התקבלה, מה נמדד
כדי להכריע אותה, ומה **נדחה ומאיזה טעם**.

**למה זה קיים.** כמה מההחלטות כאן נראות שגויות ממבט ראשון. בלי הרישום הן נשאלות
מחדש כל כמה שבועות ונענות מהתחלה, כולל המדידות. **מה שחוסך את הזמן אינו ההחלטה אלא
החלופה שנפסלה.**

## במקום אחר

הצד של השחרור בעבודה הזו — שכבת הנתונים שסקילי השחרור קוראים, האתר שהחנויות בודקות,
ותוכנית המוצר — יושב ב**מפעל האפליקציות**, שהוא ה‑repo המשלים ו‑marketplace בפני עצמו.
grove מנהל איפה הסקילים האלה נטענים; הוא אינו נושא אותם.

## הכללים לכתיבה כאן

1. **מספרים נספרים מהדיסק, לא מועתקים.** כל מספר נושא את התאריך שבו נספר.
2. **ראיה לפני נימוק.** אם נמדד — לכתוב מה נמדד ואיך. נימוק בלי מדידה מסומן ככזה.
3. **מה שהתגלה כשגוי מתוקן במקום, לא נמחק.** תיקון עם תאריך; ההיסטוריה בגיט.
4. **מסמך אחד לתפקיד אחד.**
