# 2 — המחיר של גלובלי, והציר שלא נשקל

**סוג:** מסמך בעיה, עם אפשרות רשומה **שלא הוכרעה**.
**נכתב:** 2026-09-09 · כל המדידות בוצעו באותו יום על המכונה הזו.

---

> **מאיפה המספרים.** ל‑RepoGuards שני סקילים משלו. כל מה שנמדד למטה נמדד ב**מפעל
> האפליקציות** — ה‑marketplace של מסלולי השחרור שעומד על RepoGuards — כי שם קיימת ספריית
> סקילים גדולה מספיק כדי שתהיה לה בעיית מיקום. הכלל נאכף כאן; הראיות נלקחו שם.

## בקצרה

[`1-skill-placement`](1-skill-placement.md) תמחר את הטעינה הגלובלית, מצא ~8,000
טוקנים, והכריע שהם מקובלים. **ההכרעה ההיא עומדת** — המסמך הזה אינו סותר אותה.

מה שהוא כן אומר, שניים:

**א. השאלה נשאלה כבינארית.** גלובלי (במסלול) מול מקומי (ב‑repo של הפרויקט). יש
**ציר שלישי** שלא נשקל: הסקיל נשאר במסלול, ורק **ההפעלה** שלו עוברת ל‑repo. הוא
קיים, נבדק כאן, ועובד.

**ב. למחיר יש איבר גדילה שאיש אינו מודד.** 8,000 אינו מספר קבוע — הוא רצפה.

### הגדילה — האיבר שלא נמדד עד היום

| | 2026-09-08 ([`skills/1`](1-skill-placement.md)) | 2026-09-09 | שינוי |
|---|---|---|---|

**+12% ביום אחד, משלושה סקילים.** אין כאן דליפה ואין באג — זו פשוט הצורה של
המחיר: **מונוטוני עולה, ואף אחד לא מסתכל.** אין סף, אין התרעה, ואין רגע שבו
מישהו ישווה.

*הערת שיטה:* [`skills/1`](1-skill-placement.md) מדד גם את **תיקיות** הסקילים (`references/`,

יחס 10:1. שני מדדים שונים, ושניהם תומכים באותה מסקנה: **התיאור זול מול הגוף.**
לאימות השיטה: שלושת סקילי העיצוב יוצאים כאן 1,199 תווים, זהה בדיוק ל‑[`skills/1`](1-skill-placement.md).

## הבעיה, מנוסחת

**הציר שנעדר.** [`skills/1`](1-skill-placement.md) שאל *"איפה הסקיל חי?"* והציע שתי תשובות. אבל
מיקום הקובץ והיקף ההפעלה הם **שתי שאלות**, ורק הראשונה נשאלה. אפשר שסקיל יחיה
במסלול — עם הגרסאות, ההיסטוריה והמעקות — ובכל זאת ייטען רק היכן שהוא נחוץ.

**וההצדקה של [`skills/1`](1-skill-placement.md) תלויה בזה.** הטיעון שלו היה *"סקיל גנרי שחונה בתוך
פרויקט אחד הוא בדיוק סקיל שחסר בכל מקום אחר"* — טיעון נכון נגד **מקומי**, כי
מקומי כובל את הקובץ לעץ אחד. הוא **אינו** טיעון נגד הפעלה סלקטיבית, שאינה כובלת
דבר. הציר השלישי חומק מההנמקה ההיא לגמרי.

**והמחיר גדל.** הכרעה שנכונה ב‑8,000 אינה בהכרח נכונה ב‑15,000, ואין מנגנון
שיאמר מתי עברנו.

## האפשרות — `--scope project`

**לא הוכרעה.** נרשמת כי נבדקה ועובדת, לא כי הומלצה.

`claude plugin install <track>@<marketplace> --scope project` כותב:

```json
// <repo>/.claude/settings.json
{ "enabledPlugins": { "design-track@app-factory": true } }
```

**נבדק 2026-09-09 על תיקיית דמה:**

| | |
|---|---|
| מתוך ה‑repo שהופעל בו | `Scope: project` · `Status: ✔ enabled` |
| מתוך repo אחר | `Scope: project` · `Status: ✘ disabled` |
| כל עוד הטראק מופעל גם ב‑user scope | הרשומה הפרויקטלית **לא משנה כלום** |

השורה השלישית היא התנאי: חיסכון מחייב **להסיר** את ההפעלה הגלובלית, לא רק
להוסיף פרויקטלית.

**החיסכון, בגזירה מהטבלה למעלה** — לא נמדד בסשן חי, נגזר:

| סוג repo | טראקים | עלות | נחסך |
|---|---|---|---|
| אפליקציית iOS/macOS | apple + shared | 5,629 | 2,365 · 30% |
| אפליקציית אנדרואיד | android + shared | 3,602 | 4,392 · 55% |
| Capacitor לשתי החנויות | הכל חוץ מ‑design | 7,672 | 322 · 4% |
| אתר | design | 322 | 7,672 · 96% |
| **כל השאר** | — | **0** | **7,994 · 100%** |

### המחיר של האפשרות

**כשל שקט, ומהסוג המוכר.** repo חדש של אפליקציה מתחיל בלי אף סקיל, ואיש לא
מודיע. וזה גרוע מהיעדר רגיל: *"הסקיל לא נטען"* נראה בדיוק כמו *"הסקיל החליט שהוא
לא רלוונטי"*. זו [ההתיישנות](../cross-repo-session/1-need-problem-solution.md) שוב — הקצאה שנכונה
כשנקבעה, ו‑repo חדש מבטל אותה בלי שאיש רואה.

**כתיבה ל‑repo זר.** `.claude/settings.json` נכתב לתוך repo האפליקציה, ולכן דורש
מעבר סשן לשם. המעקה יחסום מכאן, **בצדק**. מצד שני — הקובץ מתעד איזה טראקים
האפליקציה צריכה, וזה יתרון.

**הוא מגדיל את שטח ההגדרה.** היום ההפעלה במקום אחד. אחריו — בכל repo.

### הווריאנט הזול: `apple-track` בלבד

`apple-track` הוא 46% מהעלות. העברה שלו לבדו חוסכת 3,704 בכל repo שאינו אפליקציית
אפל — כלומר ברוב המוחלט של ה‑70 — ומשלמת הקמה בקומץ repos בלבד. ארבעת הנותרים
ביחד הם 4,290, ומפוזרים על ארבע הקמות.

**וסיכון ה"שקט" מוגבל שם:** מי שעומד בפרויקט Xcode ושואל על App Store יבחין
מהר שחסר לו משהו. בטראק גנרי זה יהיה הרבה פחות ברור.

## למה זה לא הוכרע כאן

**כי אין עדיין ראיה שהמחיר מזיק.** [`skills/1`](1-skill-placement.md) הכריע ש‑8,000 מקובלים, ואין
מדידה שמראה שהם פוגעים בפועל. להחליף ארכיטקטורה על סמך מספר שלא הוכח כמזיק זה
להחליף בעיה ידועה בבעיה חדשה — הכשל השקט.

**מה שכן חסר, וזול:** מדידה תקופתית של הסכום. הבעיה אינה 7,994; היא שאין רגע
שבו מישהו ישווה. לוח הבקרה של המפעל כבר מציג מצב, וזה מספר שמקומו שם.
